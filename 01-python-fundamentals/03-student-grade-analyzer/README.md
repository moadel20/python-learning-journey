# Student Grade Analyzer

A beginner Python project for storing student information and analyzing grades.

## Features

- Add student information
- Store subjects, grades, and credit hours
- Search for a student by name
- Calculate the grade average
- Find the highest and lowest grade
- Calculate the grade range
- Count passed and failed subjects
- Calculate GPA using credit hours

## Concepts Practiced

- Lists
- Dictionaries
- Functions
- Loops
- Conditional statements
- `match/case`
- Input validation
- `try/except`
- `sum()`
- `max()`
- `min()`
- `zip()`

## How to Run

Make sure Python is installed, then run:

```bash
python main.py
```
