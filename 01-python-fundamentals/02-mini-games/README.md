# Python Mini Games

A collection of simple command-line games built with Python while learning programming fundamentals.

## Games

### 1. Rock Paper Scissors

Play Rock Paper Scissors against the computer. The first player to reach 3 points wins.

### 2. Guess the Number

The computer chooses a number from 1 to 10. You have three attempts to guess it.

### 3. Guess the Color Ball

The computer chooses a random ball color, and you try to guess the correct color.

## Concepts Practiced

- Python functions
- Lists
- Loops
- Conditional statements
- `match/case`
- Error handling with `try/except`
- The `random` module
- User input
