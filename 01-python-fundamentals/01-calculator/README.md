# Python Calculator

A simple command-line calculator built with Python as part of my Python learning journey.

## Features

This calculator supports:

- Addition
- Subtraction
- Multiplication
- Division
- Power
- Remainder
- Floor division
- Square root
- Cube root
- Input validation
- Handling division by zero

## Concepts Practiced

- Variables
- Functions
- `while` loops
- Conditional statements
- `try/except`
- User input
- The `math` module
- Basic arithmetic operations

## How to Run

Make sure Python is installed on your computer.

Open the terminal inside this folder and run:

```bash
python main.py

## Example
